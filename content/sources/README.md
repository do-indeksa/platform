# Authored sources

This directory contains only independently authored source snapshots licensed
with the rest of `content/` under CC BY-NC-SA 4.0. Original FTN/ETF exam papers
and the copyrighted FTN task manual are not stored here.

Each collection registry pins statement and solution files by SHA-256. Updating
a source therefore requires an explicit registry change and a successful
provenance audit for every derived task.
